# Writing X Posts That Qualify as Original Content

Use this whenever asked to write a post, thread, reply, or caption for X. The goal: every draft should pass X's originality bar on the first write, not need a rescue edit afterward.

## Before writing: know which lane the post is in

Ask (or infer from what the user gives you):
1. **Is this built on someone else's material** (a post, video, image, screenshot, news story, cultural moment)? Or is it fully from-scratch (the user's own reporting, opinion, experience, art)?
2. **What does the user actually know or think** that isn't already in the source material — their expertise, a data point, a contrarian take, firsthand context, humor, a prediction?

If the user can't answer #2 with something specific, stop and ask them before writing — a post can't be original if there's no original input to work from. Don't manufacture fake expertise or fabricated firsthand claims to fill the gap.

## Writing rules

**If starting from scratch (their own idea/experience/reporting):**
- Just write it well. This is the easy case — it's original by default. Focus on quality, not compliance.

**If building on existing content (a post, clip, article, screenshot):**
- Never lead with a flat description of what's already visible/known. ("This video shows a robot dancing" — cut it, it adds nothing.)
- Lead with the addition: the analysis, the context nobody else has, the counterpoint, the joke that reframes it, the "here's what this actually means" angle.
- Name the specific thing you're adding in the post itself where natural — analysis, a number, a comparison, a prediction, an inside detail. If you can't identify what that thing is, go back and ask the user for it rather than padding with generic reaction language ("wow," "this is huge," "couldn't agree more").
- Attribution isn't a substitute for value. Crediting the original creator is good practice but doesn't make a repost original — the commentary has to carry real weight on its own.

**Avoid these patterns even though they're tempting for speed:**
- Caption that just narrates the attached image/video
- "My take:" followed by a restatement of the source instead of an actual take
- Reaction-only posts ("this is wild 😂") with no substance
- Threads that are 90% quoted/paraphrased source material with a one-line original comment bolted on
- Cosmetic-only transformation: cropped image, different font overlay, sped-up clip — treat these as reposts, not original content, and say so if the user asks for this kind of edit

**Self-check before finalizing a draft**, ask: *"Would this post still be worth reading if you stripped out everything except the parts only this creator could have written?"* If what's left is thin, the post needs more substance before it goes out, not just more polish.

## Content that's automatically excluded regardless of quality

Don't write posts that are:
- Primarily about the rewards program itself, monetization strategy, or "how to maximize payouts" — flag this to the user if that's what they're asking for, since it disqualifies the post outright
- Sexually explicit or otherwise inappropriate/harmful
- Copied/paraphrased close enough to another creator's specific wording or structure that it reads as reproduction rather than original commentary
- Making claims the user can't back up — disinformation/misleading content is excluded, and fabricating "facts" to sound authoritative also creates real risk for the user

## Threads specifically

For multi-post threads, the originality test applies to the thread as a whole, not each tweet in isolation — but don't let that become an excuse to pad early tweets with pure setup/description and cram all the value into the last one. Distribute substance throughout so the whole thread reads as the creator's own construction, not a wrapper around someone else's content with a payoff at the end.

## After drafting

Briefly tell the user, in one line, what makes this draft original (e.g., "this leads with your cost-comparison, which isn't in the original post") — so they can sanity-check it themselves before posting, and so weak drafts get flagged rather than shipped on autopilot.
