# user-interview-guide

Write a user interview guide that uncovers real behavior.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a guide with intro, questions and probes. Give it the **goal**: what you need to learn.

## Process

1. Ask about past behavior, not future intent.
2. Order questions from broad to specific.
3. Plan follow-ups for vague answers.

## Output

A guide with intro, questions and probes.

## What to avoid

- Leading questions.
