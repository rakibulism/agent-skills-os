# task-breakdown

Break a large task into small steps with estimates.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a checklist with estimates. Give it the **task**: the task and its deadline.

## Process

1. Define what done looks like.
2. Split into steps under half a day.
3. Order by dependency and risk.

## Output

A checklist with estimates.

## What to avoid

- Steps that hide unknowns.
