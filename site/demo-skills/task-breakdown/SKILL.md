# task-breakdown

Break a large task into small steps with estimates.

> Demo skill on the test/demo-catalog branch, for testing the catalog at scale. Not published in the npm package.

## Process

1. Clarify the goal and the input.
2. Work through the task step by step.
3. Check the result against the goal.

## Output

A concise result in the format the task calls for.
