# user-stories

Break a feature into user stories with acceptance criteria.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need stories with criteria. Give it the **feature**: the feature description.

## Process

1. Split by user value, not by layer.
2. Write each story as role, goal and reason.
3. Add testable acceptance criteria.

## Output

Stories with criteria.

## What to avoid

- Stories that are really tasks.
