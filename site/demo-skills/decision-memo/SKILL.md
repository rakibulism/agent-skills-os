# decision-memo

Write a decision memo comparing options with a clear recommendation.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a one-page memo. Give it the **decision**: the decision and options.

## Process

1. State the decision and constraints.
2. Compare options on the same criteria.
3. Recommend one and say what would change your mind.

## Output

A one-page memo.

## What to avoid

- Burying the recommendation.
