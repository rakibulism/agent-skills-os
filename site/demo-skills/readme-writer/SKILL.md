# readme-writer

Write a README that gets a new user from zero to working in minutes.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a README in Markdown. Give it the **project**: what the project is and how it runs.

## Process

1. State what it is and who it's for in one line.
2. Give install and a minimal example.
3. Link deeper docs instead of including them.

## Output

A README in Markdown.

## What to avoid

- Badges and history before the install step.
