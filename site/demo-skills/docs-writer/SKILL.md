# docs-writer

Write task-focused docs for a feature or API.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a doc page: overview, quick start, reference. Give it the **feature**: what it does and how it's used.

## Process

1. Start with the task the reader wants to do.
2. Show a working example before options.
3. List errors and how to fix them.

## Output

A doc page: overview, quick start, reference.

## What to avoid

- Explaining internals before usage.
