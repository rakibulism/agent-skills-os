# blog-post

Draft a clear, opinionated blog post from an outline.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a titled draft with headings. Give it the **outline**: topic, audience and key points.

## Process

1. Open with the reader's problem.
2. Make one point per section with an example.
3. End with what to do next.

## Output

A titled draft with headings.

## What to avoid

- Throat-clearing introductions.
