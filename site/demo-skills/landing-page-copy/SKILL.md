# landing-page-copy

Write landing page copy that explains the product and earns the click.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need copy for hero, benefits, proof, FAQ and CTA. Give it the **product**: what it does, for whom, and proof.

## Process

1. Lead with the outcome, not the feature.
2. Back each claim with proof.
3. Answer the top objections.

## Output

Copy for hero, benefits, proof, FAQ and CTA.

## What to avoid

- Vague superlatives.
