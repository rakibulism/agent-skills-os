# support-reply

Draft a friendly, accurate support reply from a customer message.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a reply ready to send. Give it the **message**: the customer's message and account context.

## Process

1. Acknowledge the problem in their words.
2. Give the fix or next step clearly.
3. Set expectations on timing.

## Output

A reply ready to send.

## What to avoid

- Canned replies that ignore the question.
