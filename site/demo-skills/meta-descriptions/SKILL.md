# meta-descriptions

Write titles and meta descriptions that earn clicks without clickbait.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need title and description per page. Give it the **pages**: page URLs and summaries.

## Process

1. Put the main keyword early in the title.
2. Describe the page's value in the description.
3. Keep within display limits.

## Output

Title and description per page.

## What to avoid

- Duplicate descriptions across pages.
