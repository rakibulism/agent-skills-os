# product-spec

Write a one-page product spec that engineers and designers can build from.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a one-page spec. Give it the **idea**: the problem and proposed solution.

## Process

1. State the problem and who has it.
2. Define scope and what's out of scope.
3. List success metrics and open questions.

## Output

A one-page spec.

## What to avoid

- Specifying the UI before the problem.
