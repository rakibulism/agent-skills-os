# brand-voice

Describe a brand's voice and apply it to new copy.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a voice guide plus the rewritten copy. Give it the **samples**: existing copy samples.

## Process

1. Extract tone, vocabulary and sentence patterns.
2. Write do and don't examples.
3. Rewrite the new copy in that voice.

## Output

A voice guide plus the rewritten copy.

## What to avoid

- Adjectives with no examples.
