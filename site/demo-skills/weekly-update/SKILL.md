# weekly-update

Write a weekly status update people actually read.

> Demo skill: an example to show how the library looks with many skills. Not published in the npm package.

## When to use

When you need a short update with headings. Give it the **notes**: what happened this week.

## Process

1. Lead with the one thing readers must know.
2. List progress against goals.
3. Flag risks and asks clearly.

## Output

A short update with headings.

## What to avoid

- Activity logs instead of outcomes.
